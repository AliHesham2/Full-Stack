# Imported QA skills — routing catalog

Each name links to the complete pinned upstream `SKILL.md`; its adjacent `references/` files remain available. Choose by the assigned defect class, not by agent brand. Read [qa-skills-integration.md](qa-skills-integration.md) before any selection. `Conditional` means the feature/environment/brief must call for it; `Other-role task` means the Tester may contribute evidence but cannot assume ownership of that artifact or decision. No listed skill auto-installs a tool.
