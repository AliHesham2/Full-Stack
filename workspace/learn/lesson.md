# Lessons for the Template

Lessons learned while working on real projects that would help **every** project built from this
template. Reported by an actually assigned operator within the authorized project/task scope. The user reviews them
and applies the change to the template. Newest first.

A task/project-specific lesson stays in the task record identified by its actual brief. Do not recreate client-specific memory files or duplicate canonical decisions.

Each entry:

```
## YYYY-MM-DD — <the lesson, in one line>
- Project:
- What happened:
- Why the template allowed it (which file, which missing or weak rule / check):
- Proposed change (the template file + exactly what to add or change):
- Status: open / applied
```

---

Proposals require review and actual authorization before source changes. Roster grants no access to another project or permission to modify reusable templates outside the current task.
