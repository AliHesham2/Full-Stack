# Decisions Taken

The project's record of every decision taken DURING the work: the ones Claude made on its own,
and the ones from a worker's report that must be kept. Only Claude writes here; workers report
their decisions with sources and never write a decision file. A decision about a PRD, including
Claude's answer to a technical Open Question, is recorded in that PRD instead (the OQ's answer,
and its DEC-n or PKG-n row where there is one), never here too. Newest first. The user reads them later and can reverse any of them.

Each entry:

```
## YYYY-MM-DD — <the decision, in one line>
- Context (why a decision was needed):
- Options considered, and why each lost:
- Chosen, and why (cleanest option / best architecture):
- Consequences:
- Assumptions, what would re-open it, and the direction then:
- How to undo it:
```
